# Сервер игры «Суд над героями нашего времени»

Сервер многопользовательской игры. Написан на Python 3, дополнительные библиотеки не нужны.

## Развёртывание на Render

1. Откройте Render: https://render.com/
2. Нажмите **New → Web Service**.
3. Подключите GitHub и выберите репозиторий `p0luninamarine-sketch/lerm-game-server`.
4. Укажите настройки:
   - **Runtime:** Python 3
   - **Build Command:** оставьте пустым (или `pip install -r requirements.txt`, если Render требует команду)
   - **Start Command:** `python server.py`
5. Нажмите **Deploy Web Service**.
6. После запуска откройте адрес сервиса с окончанием `/health`. Должен появиться ответ `{"ok": true, "service": "court-game"}`.

## Важно: подключить сайт игры

Сайт игры размещён отдельно на GitHub Pages. После того как Render выдаст адрес вида `https://имя-сервиса.onrender.com`, этот адрес нужно будет прописать в JavaScript-файле игры вместо относительных адресов `api/...`. Без этого сайт продолжит обращаться к GitHub Pages, где API не работает.

При необходимости в Render можно добавить переменную `FRONTEND_ORIGIN` со значением `https://p0luninamarine-sketch.github.io`.

## Хранение данных

Состояние игры хранится в памяти сервера. При перезапуске или остановке сервиса текущая игровая сессия сбросится. Для одной игровой сессии это подходит; для постоянного хранения нужна база данных.
